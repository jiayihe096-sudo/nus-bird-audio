# NUS 校园寻鸟游戏 — 设计文档

> 日期：2026-07-20  
> 平台：Source Academy (JavaScript, Source §4+)  
> 开发周期：1 周

---

## 一、游戏概览

一款在 Source Academy 上运行的网页寻鸟游戏。玩家在两个 NUS 校园场景中寻找隐藏的 8 种鸟类。点击找到的鸟会播放合成叫声并弹出介绍面板。右上角显示剩余鸟类数量，全部找到后进行计分结算。

---

## 二、场景设计

### 场景 A：NUS 中央大草坪

纯代码绘制简化校园背景，包含：天空渐变、草坪、大树、花坛、草丛、栏杆、树干洞。

| # | 鸟名 | 英文名 | 藏身位置 | 难度 |
|---|------|--------|----------|------|
| 1 | 黄臀鹎 | Yellow-vented Bulbul | 树冠枝叶间 | ⭐ |
| 2 | 爪哇八哥 | Javan Myna | 草地上 | ⭐ |
| 3 | 家麻雀 | Eurasian Tree Sparrow | 草丛中 | ⭐⭐ |
| 4 | 斑姬地鸠 | Zebra Dove | 路边花坛上 | ⭐⭐ |
| 5 | 领角鸮 | Collared Scops Owl | 树干洞里（只露半身+眼睛） | ⭐⭐⭐⭐ |

鸟类部分隐藏：用树叶/草丛/树洞做前景遮挡，鸟身露出 40%-80% 不等。越难找的鸟露出越少。

### 场景 B：COM3 餐厅

纯代码绘制简化室内/室外就餐区，包含：餐桌、椅子、餐具、建筑轮廓。

| # | 鸟名 | 英文名 | 藏身位置 | 类型 |
|---|------|--------|----------|------|
| 6 | 红原鸡 | Red Junglefowl | 栏杆上/餐厅附近 | 普通 |
| 7 | 鸽子 A | Rock Pigeon | 从天而降落到餐桌 | 🎭 剧情触发 |
| 8 | 鸽子 B | Rock Pigeon | 另一处直接可见 | 普通 |

### 场景切换

画面底部按钮切换场景，按钮文字显示场景名和进度：
- `🌿 中央大草坪 (3/5)` / `🍽️ COM3 餐厅 (1/3)`

两个场景各自统计，总数为 8。

## 三、核心交互流程

### 普通鸟类

```
鼠标悬停鸟身 → 光标变为指针（可选）
点击鸟身 → 播放合成叫声 → 弹出介绍面板 → 点击"关闭"按钮关闭面板
右上角计数 -1 → 小鸟图标动画反馈
```

### 鸽子 A 剧情触发（场景 B）

```
点击"吃饭的人" 
  → 人头上冒出气泡💭，气泡内画出勺子/筷子
  → 1.5 秒后气泡消失
  → 人消失
  → 人在餐具位置重新出现（拿餐具状态）
  → 鸽子从天而降（动画：y 坐标从顶部移动到餐桌）
  → 玩家点击鸽子 → 播放叫声 → 弹出介绍
```

此剧情中的动画分步实现，每步用定时器控制。剧情进行中不响应其他点击。

### 点击检测

- 每只鸟维护一个包围矩形（`{x, y, width, height}`）
- 鼠标点击时遍历当前场景所有"活跃"的鸟，判断点击坐标是否在矩形内
- 误点（点空处）计数 +1，用于最终评分

## 四、鸟类视觉实现

### 主方案：图片加载

从 URL 加载透明背景的鸟类 PNG 图片，缩放到合适大小放置在场景中。

- 图片来源：维基百科 / eBird 等公开资源
- 上传到稳定图床获取直链 URL
- 每只鸟的点击检测基于图片的放置坐标和缩放后尺寸

### 后备方案：代码绘制

如果某只鸟的图片加载失败，自动降级为代码绘制版本。

代码绘制特征表：

| 鸟名 | 主色调 | 关键特征 | 绘制方法 |
|------|--------|----------|----------|
| 黄臀鹎 | 棕色 #8B6914 | 黄色臀部圆点 | `circle`(眼) + `ellipse`(身) + 黄色小圆(臀) |
| 爪哇八哥 | 深灰 #3A3A3A | 黄色眼斑 | `ellipse`(身) + `circle`(头) + 黄色小圆(眼斑) |
| 家麻雀 | 棕色 #A0522D | 小只、白颊 | `ellipse`(身) + `circle`(头) + 白色条纹(颊) |
| 斑姬地鸠 | 灰褐 #8B8682 | 脖子斑纹 | `ellipse`(身) + 黑白条纹(颈) |
| 红原鸡 | 红棕 #8B3A3A | 红色冠、大只 | `ellipse`(大身) + `triangle`(冠) + `circle`(头) |
| 领角鸮 | 灰棕 #6B5B4B | 大圆眼、树洞半露 | `circle`(大眼×2) + `ellipse`(半身) |
| 鸽子 | 灰色 #808080 | 彩虹颈 | `ellipse`(身) + `circle`(头) + 渐变色(颈) |

## 五、音效设计

使用 Source Academy 的 `play_sound` 合成音效。每种鸟有独特的声音签名：

| 鸟名 | 频率模式 | 节奏 | 描述 |
|------|----------|------|------|
| 黄臀鹎 | 800→1200 Hz | 短-长-短 | 清脆上扬鸣叫 |
| 爪哇八哥 | 400→600 Hz | 快-快-快-慢 | 响亮多变 |
| 家麻雀 | 1000→900 Hz | 啾-啾-啾 | 短促清脆 |
| 斑姬地鸠 | 300→400 Hz | 咕——咕—— | 低沉缓慢 |
| 红原鸡 | 500→800 Hz | 咯咯咯！ | 响亮急促 |
| 领角鸮 | 250→300 Hz | 呼——呼—— | 低沉悠长 |
| 鸽子 | 350→350 Hz | 咕咕～咕 | 平稳咕叫 |

每种鸟的实际实现用多个 `play_sound` 调用配合 `setTimeout` 创造节奏感。

## 六、UI 组件

### 右上角计数器
- 小鸟图标（代码绘制） + `× 剩余数`
- 找到一只鸟时数字刷新，图标短暂缩放动画

### 介绍弹窗
- 居中弹出，半透明背景遮罩
- 内容：鸟名（中文 + 英文）+ 习性描述
- "关闭"按钮，点击后关闭弹窗，恢复游戏

### 场景切换按钮
- 画面底部，两个按钮并排
- 当前场景高亮，显示进度 `(已找到/该场景总数)`

### 通关结算画面
- 找齐全部 8 只后自动弹出
- 显示："🎉 恭喜！你找到了 NUS 所有常见鸟类！"
- 评分公式：`评分 = max(0, 1000 - 用时秒数×2 - 误点次数×10)`
- 评级：⭐（<300）/ ⭐⭐（300-600）/ ⭐⭐⭐（600+）
- "再玩一次"按钮

## 九、边界情况与错误处理

- 图片加载失败 → 自动降级为代码绘制版本
- 玩家快速点击（点击检测防抖）→ 弹窗打开期间屏蔽其他点击
- 鸽子剧情进行中 → 屏蔽其他点击，防止状态混乱
- 浏览器刷新 → 游戏重置（Source Academy 环境下不持久化状态，可接受）
- 所有鸟已找到 → 场景切换按钮替换为"查看结果"，引导结算
- 重复点击已找到的鸟 → 不做任何反应（该鸟已从活跃列表移除）
